28 July 2026

First upgrade since launch

If a page looks the same as it did yesterday, hard-refresh it.

Triage without leaving Open actions

Every row now has a Review button that expands in place: the failure output, plus assign, comment and retire. Acting on a row updates that row — it no longer reloads the page and closes everything you had open.

Open actions says why it's failing

New Last pass column: the date it last passed, and a plain sentence saying whether it broke and stayed broken or fails intermittently. The review panel shows its last 20 runs as a strip. The same column now appears in the Still failing triage queue.

That distinction is the point — "broke on the 14th" and "fails one night in three" need different responses and used to look identical.

Triage rows no longer read backwards

In New failures and Fixed last night, the previous result was drawn louder than the current one, so a new failure could look like a pass. Both now show one Result column reading PASS → FAIL: old value outlined, current value solid.

New: Time tab

Where the suite's runtime goes — environment, then script, then test. Click a bar to drill down.

Sortable columns

Click a header on Open actions and on the triage queues.

Triage sorting greys itself out when a queue is truncated, and says so. Sorting 500 of 1,340 rows would put "the oldest failure among an arbitrary 500" at the top and label it "the oldest failure".

"Not run" now means something

It used to be a fixed 36 hours. That made every Monday look like the whole estate had been abandoned, and every morning made whichever environment runs first look stale — they run one after another, hours apart. It now works from when the suite actually ran.

You should see the Not run queue holding real disappearances instead of noise, and the review panel should stop offering to retire healthy tests.

Manage people

Bottom of Open actions. Deactivate an account and it stops appearing in assignee dropdowns; comments and past assignments keep their name, and it's reversible. It refuses if that person still owns open work — reassign first, so nothing ends up assigned to a name nobody can pick.

Wider, and faster

The table pages now use the width of the screen instead of stopping short of it, so long test names stop forcing a scrollbar inside the table. Sorted pages of the test list went from ~180ms to single digits.

Anything looks wrong, say so today rather than working around it.
